# Professional UI design skill

A Claude skill that makes agents design like a senior product designer: process, hierarchy, tokens, type, color, layout, craft details, and a critique checklist to run before showing work. Gigi asked for it on 2026-11-09 after the first Knotwork dashboard read as "boring" with clashing colors.

- Source: `60 Resources/Skills/professional-ui-design/SKILL.md` (this folder is the master copy; edit it here, then re-save the skill).
- Installed as a skill in Gigi's claude.ai account (Settings > Capabilities > Skills).
- Lessons baked in from Knotwork: one accent used sparingly, no two saturated hues side by side, lead with the answer instead of a KPI-card template, show 2 to 3 directions to pick from, measure against tokens.
