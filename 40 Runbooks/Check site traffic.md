# Check site traffic


1. Open Cloudflare > Web Analytics > gigiberidze.com (link in [[Links]]), in Gigi's Chrome.
2. Look at visits, page views, and Core Web Vitals (LCP, INP, CLS).
3. Record notable readings in the table in [[Traffic analytics]].
4. For Rouse, filter Web Analytics by Host = rouse.gigiberidze.com.
5. For search words, open Google Search Console > Performance > Search results (once it is set up), filter Page contains `rouse.`, and compare queries against the keyword list in [[Traffic analytics]].
